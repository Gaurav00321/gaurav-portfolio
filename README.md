# Gaurav Upadhyay - Portfolio

A modern, responsive portfolio website showcasing the work and achievements of Gaurav Upadhyay, Founder of ThinkFlowGPT.

## 🚀 About

This portfolio website highlights Gaurav Upadhyay's journey as a software developer, AI enthusiast, and founder of ThinkFlowGPT - an AI-driven workflow automation startup revolutionizing business processes with intelligent automation.

## ✨ Features

- **Modern Design**: Built with Next.js 16 and React 18 for optimal performance
- **Responsive Layout**: Fully responsive design that works seamlessly across all devices
- **Dark Mode**: Theme switching capability with next-themes
- **SEO Optimized**: Comprehensive SEO metadata and structured data for better search visibility
- **Smooth Animations**: Enhanced user experience with Framer Motion animations
- **Component Library**: Built with Radix UI components for accessibility and consistency
- **Type-Safe**: Fully typed with TypeScript for better developer experience

## 🛠️ Tech Stack

### Core
- **Framework**: [Next.js](https://nextjs.org/) 16.0.7
- **React**: 18.2.0
- **TypeScript**: 5.x
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) 3.4.17

### UI Components
- **Radix UI**: Comprehensive set of accessible UI components
- **Lucide React**: Beautiful icon library
- **Framer Motion**: Animation library for smooth interactions
- **Embla Carousel**: Lightweight carousel component

### Forms & Validation
- **React Hook Form**: Performant form handling
- **Zod**: TypeScript-first schema validation

### Additional Libraries
- **next-themes**: Theme management
- **class-variance-authority**: CSS utility for component variants
- **tailwind-merge**: Merge Tailwind CSS classes
- **date-fns**: Modern date utility library

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/gauravupadhyay-ai/gaurav-portfolio.git
   cd gaurav-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   pnpm install
   # or
   yarn install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   pnpm dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)
